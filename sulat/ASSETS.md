# Asset provenance

Sulat uses the existing, unchanged `../fonts/NotoSansTagalog-Regular.ttf` for Baybayin text. The Noto Project Authors' SIL Open Font License 1.1 is retained in `../fonts/OFL-Tagalog.txt`. The font's embedded copyright and license were checked against upstream; the source links and verification record are in [the parent asset record](../ASSETS.md).

The page retains the typing prototype's Google Fonts links. Bird, deer, fox, goat, crab, hare, camel, and fish marks (`鳥`, `鹿`, `狐`, `羊`, `蟹`, `兔`, `駱`, and `魚`) and the title's terrain are Unicode text rendered by those fonts. No image or icon set was added for Sulat.
