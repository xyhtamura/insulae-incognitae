# Asset provenance

## Tagalog font in the typing version

`fonts/NotoSansTagalog-Regular.ttf` is an existing repository asset used as a fallback for [Sulat](sulat/)'s Baybayin translations. Its embedded copyright names the 2022 Noto Project Authors and the [Noto Tagalog source repository](https://github.com/notofonts/tagalog). Its embedded license identifies SIL Open Font License 1.1, matching the [upstream license](https://github.com/notofonts/tagalog/blob/main/OFL.txt). The license is retained in `fonts/OFL-Tagalog.txt`. The font file is unchanged.
